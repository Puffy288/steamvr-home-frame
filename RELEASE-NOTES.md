A fun experiment: SteamVR Home running locally on your Frame. Explore Workshop environments, or take a world you have made along with you—no PC streaming needed. One installer handles the downloads and adds Home to your library.

**Unofficial and experimental. Created with AI assistance. Unaffiliated with Valve.**

## How to install

1. On your **Steam Frame**, select **[Download the installer — SteamVR-Home-Frame-Install.run](https://github.com/Puffy288/steamvr-home-frame/releases/download/v0.1.0/SteamVR-Home-Frame-Install.run)**. Save it in **Downloads**. This is the only file you need; you do not need a source-code ZIP.
2. Keep Steam running and signed in. Open **Konsole**, paste this using the thumbstick right-click menu, then select **Enter** on the on-screen keyboard:

   ```bash
   bash ~/Downloads/SteamVR-Home-Frame-Install.run
   ```

3. Wait for **Installed**, then open **Library → Non-Steam → SteamVR Home (Frame - Unofficial) → Play**.

New to the Frame's desktop? [Follow the controller-first beginner guide](https://github.com/Puffy288/steamvr-home-frame/blob/main/START-HERE.md) for Desktop, Chromium, downloading, and pasting the command.

No separate FEX download is needed. Setup reuses Valve's FEX runtime or asks Steam to install it automatically.

## Included

- SteamVR Home and Workshop environments running locally.
- 4× anti-aliasing, shadows, lighting, and scene effects.
- Beginner instructions, install locations, system changes, and uninstall steps.

To close Home, open its running-app panel in the dashboard and choose **Exit Game**. **Stop** on its library page also works.

Heavy environments can run slowly. Steam may download subscribed Workshop content when Home starts; letting those downloads finish can reduce stutter.
